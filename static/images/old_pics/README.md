# Old Pics (Archive)

Esta carpeta guarda imagenes retiradas del flujo activo del juego.

## Reglas

- No referenciar archivos de `old_pics` desde escenas, player o templates.
- Si una imagen vuelve a usarse, moverla a su carpeta funcional (`shared/`, `puzzleX/`, etc.).
- Evitar editar en esta carpeta salvo para limpieza o restauracion.

## Objetivo

- Reducir ruido en `static/images`.
- Mantener historial visual por si hace falta recuperar algo.
